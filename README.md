# SatzMeister

Diktieren auf dem Mac: **Fn-Taste halten, sprechen, loslassen** – der Text erscheint dort, wo der Cursor steht.

## Installieren

1. Unter [Releases](https://github.com/bastibazz/SatzMeister-Releases/releases/latest) die Datei **SatzMeister-….zip** herunterladen.
2. Doppelklick auf die ZIP-Datei, dann **SatzMeister** in den Ordner **Programme** ziehen.
3. SatzMeister aus dem Programme-Ordner starten. Oben in der Menüleiste erscheint ein Wellen-Symbol.
4. macOS fragt nach **Bedienungshilfen** und **Mikrofon** – beides erlauben
   (Systemeinstellungen → Datenschutz & Sicherheit → Bedienungshilfen → SatzMeister einschalten).
5. Auf das Symbol in der Menüleiste klicken → **Einstellungen** → **Spracherkennung** → Modell **laden** (einmalig, ca. 550 MB).

Tipp: Unter Systemeinstellungen → Tastatur „🌐-Taste drücken für“ auf **Keine Aktion** stellen.

## Updates

SatzMeister sucht einmal täglich selbst nach Updates und fragt, ob es sie installieren soll – ein Klick genügt.
Von Hand: Symbol in der Menüleiste → **Updates**.

## Bedienung

| Taste | Wirkung |
|---|---|
| Fn halten | Diktieren, beim Loslassen wird eingefügt |
| Fn zweimal tippen | Freihändig diktieren, Fn noch einmal = fertig |
| Fn + Ctrl halten | Befehlsmodus: markierten Text umschreiben lassen (braucht Online-Modus) |
